09 · 인식 · 등록 함수09 / 32

등록 함수는 이름이 아니라 저장까지 따라가야 한다

호출부
register_handler( ACTION_REMOTE_START, remote_handler );
피호출부 — 인자를 따라간다
void register_handler(int action, Handler fn) { table[next].action = action; // 최종 저장 table[next].fn = fn; }
인자 흐름
ACTION_REMOTE_START → 파라미터 action → 저장 table[next].action
remote_handler → 파라미터 fn → 저장 table[next].fn
ACTION_REMOTE_START → remote_handler
최종 쌍 저장을 못 찾으면 → REGISTRAR_STORE_NOT_REACHED

note

이름이 register라고 충분치 않은 이유: 인자가 파라미터를 거쳐 실제 슬롯 저장까지 도달해야 한다. 도달 못 하면 사유를 붙여 보류.
